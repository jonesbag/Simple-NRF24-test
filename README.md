| nRF24 Pin | ESP32 Pin | Notes             |
| --------- | --------- | ----------------- |
| VCC       | 3.3V      | NOT 5V            |
| GND       | GND       | Common ground     |
| CE        | GPIO 4    | Can change        |
| CSN       | GPIO 5    | Can change        |
| SCK       | GPIO 18   | SPI clock         |
| MOSI      | GPIO 23   | SPI MOSI          |
| MISO      | GPIO 19   | SPI MISO          |
| IRQ       | Not used  | Leave unconnected |
